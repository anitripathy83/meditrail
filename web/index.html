Why a result here is hard to fake

  • Both companies sign each handoverA box changes hands only when the receiver accepts it with its own wallet.
  • A code sealed inside the packageThe receiver has to type it, so nobody can claim a box they never held.
  • The sensor signs the temperatureThe carrier passes readings on but can't change them. Above 8 °C the box is blocked.
  • Certificates checked by fingerprintChoose the lab PDF and your browser confirms it is the manufacturer's original.

Fake and spoiled medicine look exactly like the real thing.

A counterfeit box and a heat-damaged box both pass every glance at the counter. The only way to know is to see where the box has really been.

Scroll to follow box INS-0001

  1. Made and registered

    Gulf Pharma Labs registers box INS-0001 with its batch, expiry date, attached sensor, and the fingerprint of its lab certificate.

  2. Sealed and handed over

    The manufacturer names the distributor and seals a one-time code inside the package. Only the code's fingerprint goes on the blockchain.

  3. Received with proof

    Desert Logistics opens the seal and types the code. The wrong company, or the wrong code, and the contract refuses.

  4. Kept cold, signed by the sensor

    The cold-box sensor signs every reading itself. One reading above 8 °C blocks the box for good.

  5. Sold once

    Al Noor Pharmacy sells the box. Its code is now used up, so a copied code shows up as already sold.

  6. Checked by you

    You scan the box and get one plain answer, backed by every signed step above. Nobody can edit any of it.
